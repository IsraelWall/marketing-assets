# marketing-assets

Public image host for Peter Wall Consulting social posts. Images here get linked into Buffer posts via their raw GitHub URL — this repo exists only so Buffer has a public URL to fetch from, it's not meant to be browsed.

Images live under `posts/`, one file per post, named `YYYY-MM-DD_platform_short-topic.ext`.

Raw URL pattern:
```
https://raw.githubusercontent.com/IsraelWall/marketing-assets/main/posts/<filename>
```
